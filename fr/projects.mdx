**Home** permet de reprendre un morceau récent. **Projects** affiche votre bibliothèque. Un titre reconnaissable, une couleur et une icône aident à retrouver une idée.

## Retrouver un morceau
Utilisez la recherche par nom et le tri. Les cartes affichent des informations enregistrées, comme le BPM, la dernière modification et le temps de travail. Ce n'est pas un suivi en direct de votre session.

Ouvrez le menu d'un projet par clic droit ou avec son bouton de menu :

| Action | Résultat |
| --- | --- |
| **Details** | BPM, genre, nombre de samples, temps de travail, dates, plugins et version FL Studio. |
| **Edit** | Titre, artiste, BPM, genre, description, icône, couleur et médias associés. |
| **Duplicate** | Une copie indépendante pour essayer un nouvel arrangement. |
| **Update project** | Relit le fichier enregistré et actualise les informations et samples. |
| **Open folder** | Ouvre le dossier dans le Finder ou l'Explorateur. |

Enregistrez et fermez le projet dans FL Studio avant de le modifier, dupliquer, exporter ou restaurer. Certaines actions sont désactivées lorsqu'il est détecté comme ouvert.

## Donner une identité à vos idées
Dans **Edit**, choisissez une couleur et une icône, ajoutez une image et une description courte : « voix à enregistrer », « mix à faire écouter ». Un [aperçu audio](/fr/audio-previews) permet d'entendre le morceau sans charger FL Studio.

## Catégories du nouveau design
<Info>Les onglets de catégories font partie de l'interface à venir et ne sont pas inclus dans la version publique 1.3.5. Si votre version les propose, utilisez **Category** dans le menu du projet, puis les onglets pour filtrer. **Unsorted** correspond aux projets sans catégorie.</Info>

Pour ranger un projet terminé, [archivez-le](/fr/archives). Pour partager une copie, [exportez-le](/fr/export-projects).
