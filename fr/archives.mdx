---
title: "Archiver ou supprimer un projet"
description: "Alléger la bibliothèque active en sachant exactement ce que vous conservez."
---

Archivez une idée lorsque vous souhaitez la retirer des projets actifs tout en pouvant y revenir. Pour une simple copie supplémentaire, utilisez **Export**.

## Archiver
1. Enregistrez et fermez le projet dans FL Studio.
2. Dans son menu, choisissez **Archive project**.
3. Choisissez **Spend file (.spend)** ou **Zip file (.zip)** et lisez la confirmation.
4. Attendez la fin, puis retrouvez le fichier dans **Archives**.

Une fois l'archive créée, SpendLess déplace le dossier du projet d'origine vers la corbeille.

<Warning>Le format **.spend** conserve l'apparence SpendLess, les médias et les dossiers pris en charge. Le **.zip** conserve le FLP et les samples collectés, mais pas l'image, l'aperçu ni l'historique de sauvegarde. [Comparer les formats](/fr/export-projects).</Warning>

## Reprendre un projet
Depuis **Archives**, importez l'archive dans la bibliothèque. Une fois cet import réussi, l'ancien fichier d'archive est déplacé vers la corbeille.

Copiez-le ailleurs avant l'import si vous souhaitez conserver une sauvegarde indépendante. Une archive sur le même disque ne protège pas d'une panne de ce disque.

## Supprimer
Choisissez **Delete** dans le menu et confirmez. Le dossier géré est déplacé vers la corbeille. Pour le récupérer, restaurez ce dossier avant de vider la corbeille, puis relancez SpendLess.

Supprimer une archive ne supprime pas une copie que vous auriez exportée ailleurs. Consultez [les sauvegardes](/fr/backups) pour protéger régulièrement votre travail.
