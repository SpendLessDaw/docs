---

Ouvrez **Settings** depuis le menu utilisateur. Les sections sont **Preferences**, **Templates**, **Advanced** et **About**.

## Preferences
| Réglage | Effet |
| --- | --- |
| **Artist name** | Artiste utilisé pour la configuration des projets et exports. |
| **Default tempo** | BPM de départ des nouveaux projets. |
| **Player volume** | Volume des aperçus audio. |
| **Icon contrast** | Lisibilité des icônes sur les couleurs prises en charge. |
| **Update projects** | Traitement automatique des modifications détectées. |
| **No sample alert** | Message lorsqu'une actualisation ne trouve aucun sample. |

Changer une valeur par défaut ne réécrit pas tous les projets existants. Utilisez **Edit** pour les détails propres à un projet.
