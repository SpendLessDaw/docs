---
title: "Installer SpendLess"
description: "Télécharger et ouvrir SpendLess sur Windows ou macOS, y compris les messages de sécurité."
---

Téléchargez l'installeur depuis le [site officiel SpendLess](https://spendlessdaw.app/#download). **FL Studio doit aussi être installé** pour ouvrir et modifier vos morceaux.

<Tabs>
<Tab title="macOS">
La version actuelle nécessite **macOS 13 ou ultérieur**. Le téléchargement universel fonctionne sur les Mac Intel et Apple silicon.

<Steps>
<Step title="Installer">Ouvrez le fichier **.dmg** téléchargé, puis glissez **SpendLess** dans **Applications**.</Step>
<Step title="Ouvrir">Lancez SpendLess depuis Applications. L'app n'est pas encore signée avec un certificat Developer ID ni notariée : macOS peut bloquer le premier lancement.</Step>
<Step title="Autoriser votre téléchargement officiel">Si macOS ne peut pas vérifier le développeur ou l'app, ouvrez **Réglages Système → Confidentialité et sécurité**. Retrouvez le message concernant SpendLess et choisissez **Ouvrir quand même**, si proposé, puis confirmez. Faites-le uniquement pour le téléchargement officiel que vous avez choisi d'installer.</Step>
<Step title="Autoriser la détection">Dans **Confidentialité et sécurité → Accessibilité**, activez **SpendLess**. L'app peut alors lire les titres des fenêtres FL Studio pour reconnaître le projet ouvert. Relancez SpendLess si nécessaire.</Step>
</Steps>

Consultez [le guide Apple](https://support.apple.com/fr-fr/102445). Si le message parle d'une app endommagée ou d'un logiciel malveillant, arrêtez et [demandez de l'aide](/fr/troubleshooting#demander-de-laide).
</Tab>
<Tab title="Windows">
<Steps>
<Step title="Télécharger">Choisissez **Download for Windows** sur le site et ouvrez l'installeur.</Step>
<Step title="Vérifier SmartScreen">SpendLess n'est pas encore signé avec un certificat d'éditeur reconnu. Si **Windows a protégé votre ordinateur** apparaît pour votre téléchargement officiel, choisissez **Informations complémentaires**, vérifiez l'app, puis **Exécuter quand même** si disponible.</Step>
<Step title="Terminer">Suivez l'installation, ouvrez SpendLess et terminez la configuration initiale.</Step>
</Steps>

Si cette option manque sur un ordinateur administré, contactez son administrateur. Ne désactivez pas la sécurité Windows. [En savoir plus sur SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).
</Tab>
</Tabs>

Continuez avec [votre premier projet](/fr/first-project), ou consultez [les mises à jour](/fr/updates) si l'app est déjà installée.
