---
title: "Commencer avec des modèles"
description: "Préparer des points de départ FL Studio réutilisables sans modifier vos projets source."
---

Un modèle conserve les instruments, le routage et le mixeur que vous aimez retrouver en début de session.

## Créer un modèle
1. Ouvrez **Settings → Templates → Create template**.
2. Choisissez **Import FLP** pour partir d'un fichier existant, ou **Create from default**.
3. Donnez un nom et une icône, puis validez.

SpendLess conserve une copie gérée du modèle. La création d'un projet à partir du modèle ne remplace pas le FLP source.

## Utiliser ou modifier
Dans le menu **nouveau projet (+)**, choisissez votre modèle. Chaque projet créé est indépendant.

Pour modifier le point de départ, retournez dans **Settings → Templates**, choisissez **Edit**, faites vos changements dans FL Studio et enregistrez. **Edit details** modifie le nom et l'icône.

Le modèle intégré **SpendLess Default** est en lecture seule. Créez une copie personnelle pour le personnaliser.

## Fichier manquant ou suppression
**File missing** signifie que le fichier du modèle est introuvable. Restaurez-le ou importez à nouveau le FLP. La suppression d'un modèle personnalisé déplace son fichier vers la corbeille sans supprimer les projets déjà créés avec lui.

<Tip>Conservez une copie séparée de vos modèles et de leurs samples. **Save backup** sauvegarde les projets actifs, pas la bibliothèque de modèles.</Tip>
