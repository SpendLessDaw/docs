Open **Settings** from the user menu. The settings are grouped into **Preferences**, **Templates**, **Advanced** and **About**.

## Preferences
| Setting | What it changes |
| --- | --- |
| **Artist name** | The artist used when configuring projects and exports. |
| **Default tempo** | The starting BPM for new projects. |
| **Player volume** | Audio preview playback level. |
| **Icon contrast** | Icon readability on supported project colors. |
| **Update projects** | Automatic processing when changed projects are detected. |
| **No sample alert** | A message when a project update finds no samples. |

Changing a default does not rewrite every existing project. Use a project's **Edit** action for its own details.

## Templates
Build and manage reusable FL Studio starting points. [Create your first template](/en/templates).

## Advanced
Manage project storage, the FL Studio application and data paths, and manual backups. See [storage](/en/storage), [detection](/en/detection) and [backups](/en/backups) before changing these.

## About
Find the installed app version and release information. Include the version when asking for help. [Read about updates](/en/updates).
