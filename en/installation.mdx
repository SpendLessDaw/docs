title: "How to install"
description: "Download and open SpendLess on Windows or macOS, including first-launch security messages."
---

Download your installer from the [official SpendLess website](https://spendlessdaw.app/#download). You also need **FL Studio installed** to open and edit your music projects.

<Tabs>
<Tab title="macOS">
The current macOS release requires **macOS 13 or later**. The universal download works on Apple silicon and Intel Macs.

<Steps>
<Step title="Install the app">
Download the **.dmg**, open it, and drag **SpendLess** into **Applications**.
</Step>
<Step title="Open SpendLess">
Launch it from Applications. SpendLess is not yet Developer ID signed or notarized, so macOS may block this first launch.
</Step>
<Step title="Allow your official download">
If macOS says it cannot verify the developer or check the app, open **System Settings → Privacy & Security**. Find the SpendLess message and choose **Open Anyway**, if available, then confirm. Only do this for the official download you intended to install.
</Step>
<Step title="Allow project detection">
In **System Settings → Privacy & Security → Accessibility**, enable **SpendLess**. This allows the app to read FL Studio window titles and recognize your open project. Restart SpendLess if detection does not update.
</Step>
</Steps>

For the current macOS procedure, see [Apple's guide to downloaded apps](https://support.apple.com/en-us/102445). A message about malware or a damaged app is different: stop and [contact support](/en/troubleshooting#ask-for-help).

### Updating on macOS

SpendLess notifies you when a newer version is available. Choose **Download update**, quit SpendLess, open the new **.dmg**, and drag SpendLess into **Applications** to replace the previous version. macOS updates are installed manually; the app does not install them for you.
</Tab>
<Tab title="Windows">
<Steps>
<Step title="Download the installer">
Choose **Download for Windows** on the website to download the **.exe** installer from the official [SpendLess releases](https://github.com/SpendLessDaw/spendless-releases).

Your browser may warn that the file is not commonly downloaded. Check that it came from the official website or repository. If you trust this download, use your browser's option to keep the file. The wording varies between browsers; this screenshot is an example.

<Frame caption="Example of a browser warning when downloading the Windows installer">
  <img src="/images/installation/download-suspicious-spendless-app.png" alt="Browser warning with the option to keep the SpendLess installer" />
</Frame>
</Step>
<Step title="Review SmartScreen">
SpendLess is not yet signed with a trusted publisher certificate, so Windows may show **Windows protected your PC**. For your official download, choose **More info**, check the app, then **Run anyway** if offered.

<Frame caption="Example of the Windows SmartScreen warning">
  <img src="/images/installation/install-suspicious-spendless-app.png" alt="Windows SmartScreen warning and the More info and Run anyway options" />
</Frame>
</Step>
<Step title="Complete installation">
Follow the installer, then open SpendLess and finish the first-launch setup.
</Step>
</Steps>

If **Run anyway** is unavailable on a managed computer, ask its administrator. Do not disable Windows security to install the app. [Microsoft explains SmartScreen reputation](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).
</Tab>
</Tabs>

## First launch

Follow the setup steps to locate FL Studio and choose where to store your projects. Then import an existing project or create a new one.
