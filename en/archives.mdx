---
title: "Archive or remove a project"
description: "Clear your active library while knowing exactly what you keep."
---

Archive a project when you want it out of the active library but may return to it later. Use **Export** instead when you only want an extra copy.

## Archive a finished idea
1. Save and close the project in FL Studio.
2. Open its menu and choose **Archive project**.
3. Select **Spend file (.spend)** or **Zip file (.zip)** and read the confirmation.
4. Wait for archiving to finish, then find the file in **Archives**.

After creating the archive, SpendLess moves the original managed project folder to the system trash.

<Warning>Choose **.spend** to retain SpendLess appearance, attached media and supported project folders. **.zip** keeps the FLP and collected samples, but omits the cover, preview, colors and backup history. [Compare formats](/en/export-projects).</Warning>

## Bring a project back
Open **Archives** and import the archive back into your library. After a successful import from Archives, SpendLess moves the old archive file to the system trash.

Copy the archive somewhere else first if you want to keep it as an independent backup. An archive stored on the same drive is still vulnerable to that drive failing.

## Delete a project
Choose **Delete** in the project menu and confirm. The managed project folder moves to the system trash. To recover it, restore that folder from the trash before emptying it, then reopen SpendLess.

Deleting an archive removes that archive, not a separate copy you already exported elsewhere. For routine protection, follow [the backup guide](/en/backups).
