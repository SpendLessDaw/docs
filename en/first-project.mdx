---
title: "Your first project"
description: "Connect FL Studio, import an existing track or start a fresh idea."
---

Start with one project you know well. Keep its original folder until you have opened and checked the imported copy.

<Steps>
<Step title="Complete setup">
Open SpendLess and follow the welcome screens. Let it detect **FL Studio**, or select the application yourself. Enter your artist name if you want one; you can change it later in **Settings → Preferences**.
</Step>
<Step title="Bring in your music">
Use **Import** and choose an **.flp**, **.spend**, or a **.zip containing an FL Studio project**. SpendLess creates a managed copy in its projects folder and collects the referenced samples it can locate. Wait for the import to finish.
</Step>
<Step title="Check the result">
Open the project's **Details** to inspect its BPM, samples and plugins. Open the project in FL Studio and listen to it. If anything is missing, follow [the sample guide](/en/samples) before deleting or moving the original.
</Step>
<Step title="Make music">
Work in the SpendLess copy. Save in FL Studio, then close the project or FL Studio. With **Update projects** enabled, SpendLess refreshes changed projects when they are no longer open.
</Step>
</Steps>

## Start something new
Open the **new project (+)** menu, select the default template or one of [your templates](/en/templates), enter the project details, and create it. Open it in FL Studio to begin.

## Choose where projects live
Use **Settings → Advanced → Projects folder** to open the current location. To move the library, use **Projects destination**, which transfers the projects. [Read the storage guide first](/en/storage).

<Tip>Give projects distinct titles. That makes them easier to find and helps SpendLess recognize the project open in FL Studio.</Tip>
