title: "Find and organize projects"
description: "Use project cards, search, details, artwork and duplication to keep track of your ideas."
---

Use **Home** to pick up recent work and **Projects** to browse your library. A recognizable title, color and icon make unfinished ideas much easier to revisit.

## Find the track you want
Use the search control to find a project by its name. Change the sort order to suit the session. A card shows useful saved information such as BPM, the last update and working time. These are project details, not a live recording of what you are doing.

Open a project's menu with a right-click or its menu control:

| Action | What it does |
| --- | --- |
| **Details** | Shows BPM, genre, sample count, working time, dates, plugins and FL Studio version. |
| **Edit** | Changes the title, artist, BPM, genre, description, icon, color or attached media. |
| **Duplicate** | Creates a separate project for a new arrangement or experiment. |
| **Update project** | Reads the saved project again and refreshes its information and samples. |
| **Open folder** | Opens its managed folder in Finder or File Explorer. |

Save and close the project in FL Studio before editing, duplicating, exporting or restoring it. Some menu actions are disabled while it is detected as open.

## Make projects recognizable
Choose **Edit**, pick a color and icon, and add a cover if you like. Use a short description for notes such as “verse needs vocals” or “mix ready for feedback.” An [audio preview](/en/audio-previews) helps you hear the idea without loading FL Studio.

## Categories in the new design
<Info>Category tabs are part of the upcoming interface and are not included in the public 1.3.5 release. If your version has them, use **Category** in the project menu to assign a project and the tabs to filter your library. **Unsorted** means no category is assigned.</Info>

For finished ideas, [archive them](/en/archives). To share a copy, [export the project](/en/export-projects).
