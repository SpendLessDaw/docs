---
title: "Storage and moving computers"
description: "Find your files, move the project library and understand what stays local."
---

SpendLess stores projects and settings on your computer. It does not require an account and does not automatically sync your music between computers.

## Find your files
Open **Settings → Advanced**:

| Setting | Use it to |
| --- | --- |
| **Projects folder** | Open the managed project library. |
| **Archives folder** | Open your archived .spend and .zip files. |
| **User datas folder** | Locate SpendLess's local application data. |
| **Projects destination** | Change the library location and transfer projects. |
| **DAW path** | Select the FL Studio application. |
| **FL Studio data path** | Point SpendLess to your FL Studio data folder. |

## Move the projects folder
Save and close FL Studio, make a backup, then use **Projects destination** and select the new location. Keep the app open until the transfer finishes. Reopen a project and check its samples afterward.

Use this setting instead of moving the managed library by hand. If you use an external drive, reconnect it before opening SpendLess.

## Move to another computer
1. Export important projects as **.spend** and check the exports.
2. Copy these exports, existing archives and your template FLPs to the new computer.
3. Install SpendLess, FL Studio and the required plugins and sound libraries.
4. Import the projects and check them in FL Studio before removing the old copies.

A [library ZIP backup](/en/backups) is useful for project files and samples but is not a complete app migration. Keep your source files until the new setup is verified.

## Reset settings
**Reset all datas** resets local app data; it is not the command for deleting projects. Back up your work and record your folder settings before using it. For an ordinary problem, try [troubleshooting](/en/troubleshooting) first.
