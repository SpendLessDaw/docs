---
title: "Start faster with templates"
description: "Build reusable FL Studio starting points without changing your source projects."
---

Use a template for the routing, instruments and mixer setup you want at the start of a session.

## Create a template
1. Open **Settings → Templates → Create template**.
2. Choose **Import FLP** to use an existing FL Studio file, or **Create from default** for a fresh starting point.
3. Give it a name and icon, then save.

SpendLess keeps a managed template copy. Creating a project from it does not overwrite the source FLP.

## Use and edit a template
Open the **new project (+)** menu and choose your template. Each new project is a separate copy, so you can experiment freely.

To change the starting point itself, return to **Settings → Templates**, choose **Edit**, make the changes in FL Studio and save. Use **Edit details** in the template menu to change its name or icon.

The built-in **SpendLess Default** template is read-only. Create your own copy when you want to customize it.

## Missing or unwanted templates
**File missing** means SpendLess cannot find the template file. Restore it or import the FLP again. Deleting a custom template moves its file to the system trash; it does not remove the projects already created from it.

<Tip>Keep a separate copy of important template FLPs and any samples they use. The **Save backup** action backs up active projects, not the template library.</Tip>
